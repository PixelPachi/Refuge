# Tavern Keeper's Ledger : Le Refuge des Âmes Égarées

Jeu de fan Pokémon (rogue-lite narratif) : une taverne le jour, des âmes égarées la nuit, et leurs Labyrinthes à l'aube.

**Jouer :** https://pixelpachi.github.io/Refuge/

- `index.html`, `css/`, `js/` : le jeu (voir `DEV.md` pour la carte du code)
- `js/saisons/` : tout ce qui concerne chaque âme, saison par saison
- `assets/` : illustrations (Gemini), sprites et cris
- `GEMINI.md` : images qui restent à dessiner
- `tools/`, `tests/` : outils de production et tests automatiques (non nécessaires pour jouer)
